# 074 — Merge two sorted lists

Implement `IntNode *list_merge_sorted(IntNode *a, IntNode *b)` in `074.c`.

`a` and `b` are each sorted ascending (either may be `NULL`). Return the
head of one list containing every node from both, still sorted, built by
**relinking the existing nodes** — no `malloc`, no copying of values. After
the call, `a` and `b` are no longer valid list heads; the caller owns the
returned list and frees it once.

The merge must be **stable**: when a node from `a` and a node from `b` have
equal values, the node from `a` comes first. The tests check node
addresses, not just values, so cheating by copying values fails.

Technique: keep a pointer to the tail of the result and a *pointer to the
pointer* where the next node will be attached (`IntNode **tail`). At each
step compare `a->value` and `b->value`, attach the smaller (use `<=` for
`a` to keep stability), and advance that input. When one input runs out,
attach the whole remaining other list in one assignment. A dummy head node
on the stack also works. O(n + m) time, O(1) space, no recursion.

Examples: `1 → 3 → 5` + `2 → 4` → `1 → 2 → 3 → 4 → 5`; `NULL` + `7 → 9`
→ `7 → 9` (same nodes); `NULL` + `NULL` → `NULL`; `1 → 1` + `1` → the two
nodes from `a` first, then the node from `b`.
