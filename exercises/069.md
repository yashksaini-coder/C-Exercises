# 069 — Array-backed stack

Implement `int stack_push(Stack *stack, int value)` and
`int stack_pop(Stack *stack, int *out)` in `069.c`.

`typedef struct { int items[64]; size_t count; } Stack;` — a fixed-capacity
LIFO. The caller zero-initialises it (`Stack s = {0};`), so `count` starts
at `0` and is the number of live elements; `items[count - 1]` is the top.

Contract:

- `stack_push` stores `value` at `items[count]` and increments `count`;
  returns `0` on success and `-1` when the stack already holds 64 elements
  (nothing is stored, `count` unchanged).
- `stack_pop` returns `-1` when `count == 0` (and leaves `*out` untouched);
  otherwise decrements `count`, writes the removed top into `*out` and
  returns `0`.

Pop then push must reuse the same slot. No allocation, no globals. The
capacity is `ARRAY_LENGTH(stack->items)` (macro in `exercises.h`); do not
hard-code `64` twice.

Examples: push `1, 2, 3` then pop three times → `3, 2, 1`, fourth pop →
`-1`; 64 pushes succeed, the 65th returns `-1`; pop on an empty stack →
`-1` and `*out` is unchanged.
