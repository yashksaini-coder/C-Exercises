# 033 — Structs by value

Implement `double point_distance(Point a, Point b)` in `033.c`.

`Point` is declared in `include/exercises.h` as `typedef struct { double x, y; } Point;`.
Return the Euclidean distance between `a` and `b`:
`sqrt((a.x - b.x)^2 + (a.y - b.y)^2)`. Use `sqrt` from `<math.h>`; the
Makefile already links `-lm`.

Both arguments arrive by value: the caller's structs are copied onto the
stack, so nothing you do to `a` or `b` inside the function is visible outside.
Accessing a member of a struct value uses `.`, not `->`. Passing a 16-byte
struct by value is fine; for large structs you would pass a `const Point *`
instead, which the next exercises do not need.

The distance is symmetric (`point_distance(a, b) == point_distance(b, a)`),
never negative, and zero when the points coincide. Do not use `pow` for
squaring; multiply the differences by themselves.

Examples: `(0,0)`–`(3,4)` → `5.0`; `(1,1)`–`(1,1)` → `0.0`;
`(-1,-1)`–`(2,3)` → `5.0`; `(0,0)`–`(1,1)` → `1.41421356...`.

> [!TIP]
> Read: Beej's Guide to C, §8.1 Declaring a Struct and §8.4 Passing Structs
> to Functions — https://beej.us/guide/bgc/html/split/structs.html
> Interviewers use this to check you know `.` versus `->` and value versus
> pointer semantics.

Run `make run N=33`; check with `make test N=33`.
