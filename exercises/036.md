# 036 — Enums as types

Implement `const char *day_name(Day day)` and `Day next_day(Day day)` in
`036.c`.

`Day` is `typedef enum { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY,
SATURDAY, SUNDAY, DAY_COUNT } Day;`. The constants are plain `int`s counting
from `0`, so `DAY_COUNT` is `7` and doubles as the array size — a common C
idiom.

`day_name` returns a pointer to a string literal: `"Monday"`, `"Tuesday"`,
…, `"Sunday"` (capitalized English names). The literal has static storage
duration, so returning a pointer to it is safe; do not `malloc`. For any
invalid value — `DAY_COUNT`, anything larger, or a negative number cast to
`Day` — return `"?"`. An enum variable can hold values outside its named
constants, so always range-check; a `switch` with a `default` or an array
lookup guarded by `(unsigned)day < DAY_COUNT` both work.

`next_day` returns the following day and wraps `SUNDAY` to `MONDAY`:
`(day + 1) % DAY_COUNT`. You may assume `next_day` only receives valid days.

Allowed: nothing special; no library functions needed.

Examples: `day_name(MONDAY)` → `"Monday"`; `day_name(SUNDAY)` → `"Sunday"`;
`day_name(DAY_COUNT)` → `"?"`; `day_name((Day)-1)` → `"?"`;
`next_day(SATURDAY)` → `SUNDAY`; `next_day(SUNDAY)` → `MONDAY`.
