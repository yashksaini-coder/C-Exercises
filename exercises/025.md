# 025 — Find a substring

Implement `char *my_strstr(const char *haystack, const char *needle)` in `025.c`.

Return a pointer to the first occurrence of `needle` inside `haystack`, or
`NULL` if there is none. An empty `needle` matches at the very start:
`my_strstr(haystack, "")` returns `haystack` (even when `haystack` is `""`).
Matching is byte-exact and case-sensitive.

The straightforward O(n·m) algorithm is what is expected: for each start
position `i` in `haystack`, compare `needle` against `haystack + i` byte by
byte; if you reach the end of `needle` you have a match. Stop the inner loop
on a mismatch *or* on the end of `haystack` — reading past the terminator is
the bug `SANITIZE=1` will flag, and the test with `"aaa"` / `"aaaa"` exists
to catch it. Return a `char *` to the match with a cast, as in exercise 024.

Forbidden: `strstr`, `strncmp`, `memcmp`, `strlen`, everything in
`<string.h>`. You may reuse your own `my_strlen` / `my_strcmp` by copying
them in, but a direct loop is simpler.

Examples: `my_strstr("hello world", "o w")` → pointer to index `4`;
`my_strstr("hello", "xyz")` → `NULL`; `my_strstr("hello", "")` → `hello`;
`my_strstr("aaa", "aaaa")` → `NULL`; `my_strstr("abcabc", "cab")` → index `2`.

> [!TIP]
> Read: Beej's Guide to C, §7.7 String Searching —
> https://beej.us/guide/bgc/html/split/strings.html
> Interviewers follow up with "now do it in O(n)"; know that KMP exists.

Run `make run N=25`; check with `make test N=25`.
