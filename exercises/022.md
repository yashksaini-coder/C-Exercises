# 022 — Copy a string

Implement `char *my_strcpy(char *destination, const char *source)` in `022.c`.

Copy `source`, *including* its terminating `'\0'`, into `destination` and
return `destination` (so the call can be nested, as in
`puts(my_strcpy(buffer, "hi"))`). The caller guarantees `destination` has
room for `my_strlen(source) + 1` bytes and that the two do not overlap.

The classic bug is to copy the characters but forget the terminator:
`destination` then runs on into whatever was in the buffer before. The
tests pre-fill the buffer with `'X'` so a missing NUL is visible. Walk both
pointers together; the idiomatic one-liner `while ((*d++ = *s++)) ;` copies
the NUL as its last step because an assignment expression has the value
assigned. Remember to return the *original* `destination`, not the advanced
pointer.

Forbidden: `strcpy`, `strncpy`, `memcpy`, `strlen`, everything in
`<string.h>`. You may reuse `my_strlen` (copy it in) but you do not need it.

Examples: `my_strcpy(buffer, "hello")` → `buffer` holds `"hello"`, return
value `== buffer`; `my_strcpy(buffer, "")` → `buffer` holds `""`;
copying `"a"` into a 2-byte buffer works.

> [!TIP]
> Read: Beej's Guide to C, §7.5 Copying a String —
> https://beej.us/guide/bgc/html/split/strings.html
