# 080 — Command-line arguments

Implement `int parse_args(int argc, char **argv, Options *out)` in `080.c`.

`typedef struct { int count; bool verbose; const char *output; } Options;`

`argv` has the shape `main` receives: `argv[0]` is the program name and is
skipped; `argv[argc]` is `NULL`. Recognised flags, in any order and any
number of times (later wins):

- `-n <int>` sets `count` (default `1`). Parse the value with `strtol`;
  reject it if it is empty or has trailing junk (`"12x"`).
- `-v` sets `verbose = true` (default `false`).
- `-o <path>` sets `output` to point at the `argv` string (default `NULL`).
  Do not copy it; `argv` outlives the options.

Start by writing the defaults into `*out`. Return `0` on success. Return
`-1` for an unknown argument (anything that is not one of the three flags,
including a bare word) or a flag whose value is missing (`-n` as the last
argument). On `-1` the contents of `*out` are unspecified, so the tests do
not read them.

`-n` may take a negative value; `-n -5` is valid. The classic bug is
reading `argv[i + 1]` without first checking `i + 1 < argc`. Use `strcmp`
for the flag names; `getopt` is not allowed (it is POSIX, keeps global
state, and hides exactly what this exercise teaches).

Examples: `{"prog", "-n", "3", "-v"}` → `count 3, verbose true, output
NULL`; `{"prog"}` → defaults; `{"prog", "-o", "out.txt", "-n", "7"}` →
`output "out.txt", count 7`; `{"prog", "-x"}` → `-1`; `{"prog", "-n"}` →
`-1`; `{"prog", "-n", "12x"}` → `-1`.
