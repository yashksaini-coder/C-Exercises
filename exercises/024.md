# 024 — Find a character

Implement `char *my_strchr(const char *s, int c)` in `024.c`.

Return a pointer to the first occurrence of `c` in `s`, or `NULL` if it does
not occur. Like the real `strchr`, `c` is passed as an `int` but compared as
a `char` (convert with `(char)c`), and the terminating `'\0'` counts as part
of the string: `my_strchr(s, '\0')` returns a pointer to the terminator,
never `NULL`. That detail is why the loop must test for a match *before*
checking for the end of the string, or be written as a `do`/`while`.

The return type is `char *` even though the input is `const char *`; that
is the (unfortunate) signature of the standard function, so you need a cast
on the way out: `return (char *)p;`. Searching an empty string for anything
but `'\0'` returns `NULL`.

Forbidden: `strchr`, `strrchr`, `memchr`, `strlen`, everything in
`<string.h>`.

Examples: `my_strchr("hello", 'l')` → pointer to index `2`;
`my_strchr("hello", 'z')` → `NULL`; `my_strchr("hello", '\0')` → pointer to
index `5`; `my_strchr("", 'a')` → `NULL`.

> Read: Beej's Guide to C, §7.7 String Searching —
> https://beej.us/guide/bgc/html/split/strings.html
