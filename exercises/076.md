# 076 — Binary search tree

Implement `int bst_insert(TreeNode **root, int value)`,
`bool bst_contains(const TreeNode *root, int value)` and
`void bst_free(TreeNode *root)` in `076.c`.

`typedef struct TreeNode { int value; struct TreeNode *left, *right; } TreeNode;`
An empty tree is `NULL`. The invariant: every value in a node's left
subtree is smaller than the node's value, every value in its right subtree
is larger. Duplicates are not stored.

Contract:

- `bst_insert(&root, v)` walks down from the root choosing left or right
  until it reaches a `NULL` link, then `malloc`s a leaf there. Returns `0`
  if a node was inserted, `1` if `v` was already present (tree unchanged,
  nothing allocated), `-1` if `malloc` fails. Like 071, the `TreeNode **`
  parameter lets inserting into an empty tree set the caller's `root`.
  The neat iterative version keeps a `TreeNode **link` and walks
  `link = &(*link)->left` / `->right`; recursion is also fine.
- `bst_contains(root, v)` follows the same comparison path and returns
  `true` if it finds `v`. O(height).
- `bst_free(root)` frees every node. Use post-order: free both subtrees
  *before* the node itself, since you need the node to reach its
  children. `bst_free(NULL)` is a no-op.

No balancing is required; inserting sorted input produces a degenerate
chain and that is accepted here (077 measures it).

Examples: insert `5, 3, 8, 1, 4` → contains `4` is `true`, contains `7` is
`false`; inserting `3` again → returns `1`; `bst_contains(NULL, 1)` →
`false`; after inserts of `5, 3, 8`, `root->left->value == 3` and
`root->right->value == 8`.
