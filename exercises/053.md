# 053 — Reverse 32 bits

Implement `uint32_t reverse_bits(uint32_t value)` in `053.c`.

Return `value` with its bit order reversed: bit 0 becomes bit 31, bit 1
becomes bit 30, and so on. This is a *bit* reversal, not a byte swap
(`0x12345678` byte-swapped is `0x78563412`; bit-reversed it is
`0x1E6A2C48`).

The direct method: loop 32 times, shift the result left by one, OR in the
lowest bit of `value`, shift `value` right by one. Always use the
`uint32_t` type for both so the shifts are well-defined and the result
does not pick up sign bits. The divide-and-conquer version (swap adjacent
bits, then pairs, then nibbles, bytes, halves — five masked steps) runs in
constant time and is worth knowing for the follow-up question.

Forbidden: compiler builtins and lookup tables over 256 entries that you
did not generate in the function.

Examples: `reverse_bits(0)` → `0`; `reverse_bits(1)` → `0x80000000`;
`reverse_bits(0x80000000)` → `1`; `reverse_bits(0x12345678)` →
`0x1E6A2C48`; `reverse_bits(0xFFFFFFFF)` → `0xFFFFFFFF`;
`reverse_bits(reverse_bits(x)) == x`.

> Read: Beej's Guide to C, ch. 24 Bitwise Operations, §24.2 Bitwise Shift —
