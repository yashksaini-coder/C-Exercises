# 023 — Compare strings

Implement `int my_strcmp(const char *a, const char *b)` in `023.c`.

Compare `a` and `b` byte by byte. Return `0` when they are identical, a
negative value when `a` sorts before `b`, and a positive value when `a` sorts
after `b`. Only the *sign* of the result is specified (the tests check
`(r > 0) - (r < 0)`), so returning the difference of the first mismatching
bytes is fine.

Walk both strings while the current bytes are equal and neither is `'\0'`;
then return the difference of the bytes at that position. A shorter string
that is a prefix of a longer one sorts first because its `'\0'` (0) is less
than any other byte. Compare as `unsigned char`: `char` may be signed, and
then a byte such as `0xE9` (`'é'` in Latin-1 / the lead byte of UTF-8
`"é"`) would compare *less* than `'a'` instead of greater. The tests include
such a byte.

Forbidden: `strcmp`, `strncmp`, `memcmp`, everything in `<string.h>`.

Examples: `my_strcmp("abc", "abc")` → `0`; `my_strcmp("abc", "abd")` →
negative; `my_strcmp("b", "a")` → positive; `my_strcmp("ab", "abc")` →
negative; `my_strcmp("", "")` → `0`; `my_strcmp("\xE9", "a")` → positive.

> Read: Beej's Guide to C, §7.6 String Comparison —
> https://beej.us/guide/bgc/html/split/strings.html
> and §14.1 Signed and Unsigned Char —
> https://beej.us/guide/bgc/html/split/types-ii-way-more-types.html
