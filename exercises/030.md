# 030 — String to int with clamping

Implement `int my_atoi(const char *s)` in `030.c`.

Parse an integer from the start of `s` with these steps, in order:

1. Skip leading whitespace (as `isspace` defines it).
2. Accept one optional `'+'` or `'-'`.
3. Read decimal digits until the first non-digit (or the end). Everything
   after that is ignored.
4. If no digits were read, return `0`. Otherwise return the value, clamped
   to `INT_MAX` or `INT_MIN` if it does not fit.

This is the LeetCode 8 contract, not the real `atoi` (which is undefined
on overflow). `"  -42abc"` → `-42`; `"abc"` → `0`; `"+"` → `0`;
`"99999999999"` → `INT_MAX`; `"-99999999999"` → `INT_MIN`.

Accumulate in a `long long`, or better, check *before* each
`result = result * 10 + digit` whether it would exceed the limit:
`result > (INT_MAX - digit) / 10` means it will. The second form is the one
that generalises to the widest type. Do not use `strtol`, `atoi`, `sscanf`
or any conversion function; `isdigit`/`isspace` from `<ctype.h>` are fine
(cast to `unsigned char`). Note that `INT_MIN` has a larger magnitude than
`INT_MAX`; `"-2147483648"` must return exactly `INT_MIN`, not clamp to
`-INT_MAX`.

Examples: `"42"` → `42`; `"   -42"` → `-42`; `"4193 with words"` → `4193`;
`"words and 987"` → `0`; `"-91283472332"` → `INT_MIN`; `"2147483647"` →
`INT_MAX`; `"-2147483648"` → `INT_MIN`.
