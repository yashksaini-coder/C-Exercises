# 014 — Rotate by k

Implement `void array_rotate_left(int *values, size_t count, size_t k)` in `014.c`.

Rotate `values[0..count)` left by `k` positions in place: each element moves
from index `i` to index `(i - k) mod count`, so `{1, 2, 3, 4, 5}` rotated by
`2` becomes `{3, 4, 5, 1, 2}`. `k` may be any value, including `k >= count`
and `k == 0`: reduce it first with `k %= count`, which also makes `k == count`
a no-op. When `count` is `0` do nothing (`values` may be `NULL`; do not
compute `k % 0`, that is a divide by zero).

Do it in O(count) time and O(1) extra space. The suggested technique is the
three-reversals trick: reverse the first `k` elements, reverse the remaining
`count - k`, then reverse the whole array. Rotating one position at a time
`k` times is O(count · k) and is the "it works but it's slow" answer. Use
your `array_reverse` from exercise 013 (copy it in as a `static` helper).
No `<string.h>`, no temporary array.

Examples: `{1, 2, 3, 4, 5}, k = 2` → `{3, 4, 5, 1, 2}`;
`{1, 2, 3, 4, 5}, k = 7` → `{3, 4, 5, 1, 2}`; `{1, 2, 3}, k = 3` →
`{1, 2, 3}`; `{1, 2, 3}, k = 0` → `{1, 2, 3}`; `count == 0` → nothing.
