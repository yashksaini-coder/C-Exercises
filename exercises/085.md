# 085 — va_list and vsnprintf

Implement `int log_message(char *buffer, size_t capacity, const char *level, const char *format, ...)`
in `085.c`.

Write `"[LEVEL] message"` into `buffer`, where `LEVEL` is the `level`
string as given and `message` is `format` expanded with the remaining
arguments exactly as `printf` would. Return what `snprintf` would return
for the whole string: the number of characters that *would* have been
written if `capacity` were unlimited, not counting the terminating `'\0'`.
When that number is `>= capacity` the output is truncated to
`capacity - 1` characters plus `'\0'`; when `capacity` is `0` nothing is
written (and `buffer` may be `NULL`).

You cannot forward `...` to another variadic function; you forward a
`va_list`. The pattern is the one every logging library uses:

```c
va_list args;
va_start(args, format);
int n = vsnprintf(buffer + used, capacity - used, format, args);
va_end(args);
```

Write the prefix with `snprintf` (it returns the length even when
truncated), then the message with `vsnprintf` at the offset. Take care
when the prefix alone already overflowed: the offset must be clamped to
`capacity` so the second call gets a size of `0`, not a huge `size_t`
from an underflow. Do not build the message in a separate fixed-size
temporary: that reintroduces a limit the caller cannot see.

Examples: `log_message(buf, 64, "INFO", "x=%d", 5)` → `buf` is
`"[INFO] x=5"` and the return is `10`; with `capacity 6` → `buf` is
`"[INFO"` and the return is still `10`; `capacity 0, buffer NULL` →
return `10`, nothing written; `log_message(buf, 64, "WARN", "%s!",
"careful")` → `"[WARN] careful!"`, `15`.
