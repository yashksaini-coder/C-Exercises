# 028 — Trim whitespace in place

Implement `char *trim(char *s)` in `028.c`.

Remove leading and trailing whitespace from `s` in place and return `s`
itself — the *same* pointer that was passed in, never a pointer into the
middle of the buffer. Whitespace is whatever `isspace` says: space, `\t`,
`\n`, `\v`, `\f`, `\r`. Interior whitespace is kept. An all-whitespace or
empty string becomes `""`.

Returning `s + leading` is tempting and wrong: the caller may later `free`
the pointer it holds, or expect `s` itself to hold the result. So the
content has to move to the front of the buffer. Find the first
non-whitespace byte and the last one, shift the bytes between them to index
`0` with a loop (`memmove` is the library's way; here write the loop
yourself), and write `'\0'` after them. Because the shift is leftward, a
simple forward copy is safe even though source and destination overlap.

Forbidden: everything in `<string.h>` (`strlen`, `memmove`, `strcpy`).
`<ctype.h>` is allowed; pass it `unsigned char`.

Examples: `"  hello  "` → `"hello"`; `"\t\n x y \r\n"` → `"x y"`;
`"hello"` → `"hello"`; `"   "` → `""`; `""` → `""`. In every case the
return value `== s`.
