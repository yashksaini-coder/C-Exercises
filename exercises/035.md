# 035 — qsort comparator on structs

Implement `int compare_students(const void *a, const void *b)` in `035.c`.

`Student` is `typedef struct { char name[32]; int score; } Student;`. Write
the comparator `qsort` needs to order an array of `Student` by `score`
*descending* (highest first) and, for equal scores, by `name` *ascending*
using `strcmp`.

`qsort` hands you two `const void *`; cast each to `const Student *` before
touching members. The return value follows the `strcmp` convention: negative
when `a` sorts before `b`, positive when `a` sorts after `b`, zero when they
are equivalent. Because scores are `int`, do **not** return `b->score - a->score`:
that overflows for large magnitudes (`INT_MIN` versus a positive score). Use
comparisons (`(x > y) - (x < y)`) or `if` chains instead.

`strcmp` from `<string.h>` and `qsort` from `<stdlib.h>` are allowed; the
tests call `qsort(students, count, sizeof(Student), compare_students)` and
check the resulting order.

Examples: `{"bob",90}` vs `{"amy",80}` → negative (90 sorts first);
`{"bob",90}` vs `{"amy",90}` → positive (`"amy"` before `"bob"`);
`{"amy",90}` vs `{"amy",90}` → `0`. Sorting
`[{"cat",70},{"amy",90},{"bob",90},{"dan",100}]` gives
`dan, amy, bob, cat`.
