# 006 — Sum of digits

Implement `int digit_sum(int value)` in `006.c`.

Return the sum of the decimal digits of `|value|`: `digit_sum(-123)` is
`1 + 2 + 3 = 6`. Zero has digit sum `0`.

The whole input range is valid, including `INT_MIN`. The obvious first move,
`if (value < 0) value = -value;`, is undefined behaviour for `INT_MIN`
because `2147483648` does not fit in an `int` (`make test N=6 SANITIZE=1`
will catch it). Do not negate. Instead peel digits with `value % 10` and
`value / 10`: for a negative `value`, `%` yields a digit in `-9..0`, so take
the absolute value of each *digit* rather than of the whole number. Keep the
loop condition `value != 0`, not `value > 0`, or negatives sum to zero.

No `abs`, no `<math.h>`, no conversion to a string.

Examples: `digit_sum(0)` → `0`; `digit_sum(1234)` → `10`; `digit_sum(-123)`
→ `6`; `digit_sum(INT_MAX)` → `46`; `digit_sum(INT_MIN)` → `47`.
