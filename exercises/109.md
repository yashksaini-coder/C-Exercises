# 109 — Balanced brackets

Implement `bool balanced_brackets(const char *s)` in `109.c`.

Return `true` when every opening bracket in `s` (`(`, `[`, `{`) is closed
by the matching closer (`)`, `]`, `}`) in the right order, and `false`
otherwise. Characters other than the six brackets are ignored. The empty
string is balanced.

The algorithm is a stack: push each opener; on a closer, the stack must be
non-empty and its top must be the matching opener, which you pop; at the
end the stack must be empty. Use a fixed `char stack[1024]` on the C
stack plus a depth counter, no `malloc`. If nesting depth would exceed
1024 (the 1025th unmatched opener), return `false`: a parser with a bound
is safer than one that overflows.

The classic first-attempt bugs: forgetting that a closer with an empty
stack is a failure (`")("`), and forgetting that leftover openers at the
end are a failure (`"(("`). `"([)]"` must be `false`: the *order* matters,
not just the counts.

No library calls are needed; no global state.

Examples: `balanced_brackets("()")` → `true`;
`balanced_brackets("([]{})")` → `true`;
`balanced_brackets("{ a[0] = (b + c); }")` → `true`;
`balanced_brackets("([)]")` → `false`; `balanced_brackets("((")` →
`false`; `balanced_brackets(")(")` → `false`; `balanced_brackets("")` →
`true`; 1025 `(` → `false`.
