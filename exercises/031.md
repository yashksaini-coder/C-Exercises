# 031 — Int to decimal string

Implement `int int_to_string(int value, char *destination, size_t capacity)` in `031.c`.

Write the decimal representation of `value` into `destination` — a leading
`'-'` for negatives, the digits, and a terminating `'\0'` — and return the
number of characters written, *not* counting the NUL. If the text plus the
NUL does not fit in `capacity` bytes, write nothing except `destination[0]
= '\0'` (when `capacity > 0`) and return `-1`. `capacity == 0` returns `-1`
and touches nothing.

Produce the digits yourself. Repeated `value % 10` and `value / 10` yield
them from least significant to most significant, so either write them into
a temporary buffer and reverse, or write from the end of the computed
length backwards. Handle `INT_MIN` without negating it: `-INT_MIN` overflows
(see exercise 006). Either work with negative remainders (`-8 % 10 == -8`,
take its absolute value) or accumulate in an `unsigned`. `0` must produce
`"0"` — a loop that runs while `value != 0` writes nothing for it.

Forbidden: `sprintf`, `snprintf`, `itoa`, `strlen`, everything in
`<string.h>` and `<stdio.h>` for the conversion. You may reuse
`reverse_string` (026) by copying it in.

Examples (`capacity` 16 unless noted): `0` → `"0"`, returns `1`; `42` →
`"42"`, `2`; `-7` → `"-7"`, `2`; `INT_MIN` → `"-2147483648"`, `11`;
`123` with capacity `3` → `-1` and `destination[0] == '\0'`; `123` with
capacity `4` → `"123"`, `3`.
