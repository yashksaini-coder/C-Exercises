# 090 — Format dotted-quad

Implement `int format_ipv4(const uint8_t address[4], char *destination, size_t capacity)`
in `090.c`.

Write the four bytes of `address` as decimal numbers separated by dots into
`destination`, NUL-terminated, and return the number of characters written
(not counting the NUL). The result is between 7 (`"0.0.0.0"`) and 15
(`"255.255.255.255"`) characters long, so a 16-byte buffer always suffices.

If the full string plus its NUL does not fit in `capacity`, return `-1` and
write nothing (leave `destination` untouched, so a caller cannot mistake a
truncated prefix for a real address). `capacity == 0` or `destination == NULL`
is also `-1`. No leading zeros in the output: `10` is `"10"`, never `"010"`.

Build the string by hand: convert each byte to up to three digits, append a
dot between octets. `snprintf("%u.%u.%u.%u")` is the one-liner you would use
at work; here it is forbidden, as are `inet_ntop`, `inet_ntoa` and `sprintf`.
Computing the length *before* writing is the clean way to handle the
too-small case.

Examples: `format_ipv4({192, 168, 1, 10}, buf, 16)` → `12`, `buf` is
`"192.168.1.10"`; `format_ipv4({0, 0, 0, 0}, buf, 8)` → `7`;
`format_ipv4({0, 0, 0, 0}, buf, 7)` → `-1` (no room for the NUL);
`format_ipv4({255, 255, 255, 255}, buf, 16)` → `15`.
