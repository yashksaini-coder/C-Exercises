# 010 — Loops with unsigned 64-bit

Implement `int collatz_steps(uint64_t n)` in `010.c`.

The Collatz step maps `n` to `n / 2` when `n` is even and to `3n + 1` when
it is odd. Return how many steps it takes to reach `1` starting from `n`.
`collatz_steps(1)` is `0` (already there). `0` never reaches `1`: return
`-1` for it. The sequence is conjectured to reach `1` for every positive
start, and it does for every value the tests use.

The parameter is `uint64_t`, so the arithmetic is unsigned 64-bit: `n % 2`,
`n / 2` and `3 * n + 1` all stay in that type. Make sure your loop condition
is `n != 1`, not `n > 1`, and that any temporary you introduce is also a
`uint64_t` — an `int` temporary silently truncates the peak values (the
trajectory from 27 climbs to 9232, and larger starts go far above
`UINT32_MAX`). The tests pass `1ULL << 40` and `1ULL << 63`, which take
exactly 40 and 63 halvings; a 32-bit mix-up fails those immediately. No
recursion, no library calls.

Examples: `collatz_steps(1)` → `0`; `collatz_steps(6)` → `8`;
`collatz_steps(27)` → `111`; `collatz_steps(0)` → `-1`;
`collatz_steps(1ULL << 40)` → `40`.
