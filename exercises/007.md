# 007 — Fibonacci without recursion

Implement `uint64_t fibonacci(unsigned n)` in `007.c`.

Return the n-th Fibonacci number with `fibonacci(0) = 0`, `fibonacci(1) = 1`
and `fibonacci(n) = fibonacci(n - 1) + fibonacci(n - 2)`. Use a loop that
keeps the two previous values; no recursion (the naive recursive version is
exponential and `fibonacci(90)` would never finish).

The return type is `uint64_t` from `<stdint.h>`, already included through
`exercises.h`. `fibonacci(93) = 12200160415121876738` is the largest value
that fits; the tests go no higher, so you do not need to detect overflow.
Keep the running values in `uint64_t` too: an `int` or `unsigned` wraps
around at `fibonacci(47)` / `fibonacci(48)`. Print a `uint64_t` with the
`PRIu64` macro from `<inttypes.h>`.

Examples: `fibonacci(0)` → `0`; `fibonacci(1)` → `1`; `fibonacci(10)` → `55`;
`fibonacci(50)` → `12586269025`; `fibonacci(93)` → `12200160415121876738`.
