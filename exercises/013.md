# 013 — Reverse in place

Implement `void array_reverse(int *values, size_t count)` in `013.c`.

Reverse the order of `values[0..count)` in place: no second array, no
allocation. Walk two indices toward each other from both ends and swap the
pairs; stop when they meet. `count` of `0` or `1` must be a no-op (`values`
may be `NULL` when `count` is `0`).

Be careful with the loop bound: iterating `i` from `0` to `count - 1` and
swapping `values[i]` with `values[count - 1 - i]` swaps every pair *twice*
and leaves the array as it was. Loop while `i < count / 2`, or keep
`left < right` with two indices. Also remember `size_t` is unsigned:
`count - 1` when `count == 0` is `SIZE_MAX`, not `-1`, so guard that case
before computing it.

You may call `swap_int` from exercise 011 if you copy it into this file.
No `<string.h>`, no `memcpy`.

Examples: `{1, 2, 3, 4}` → `{4, 3, 2, 1}`; `{1, 2, 3}` → `{3, 2, 1}`;
`{7}` → `{7}`; `count == 0` → nothing happens.

> [!TIP]
> Read: Beej's Guide to C, §6.5 Arrays and Pointers and §6.6 Passing arrays
> to functions — https://beej.us/guide/bgc/html/split/arrays.html

Run `make run N=13`; check with `make test N=13`.
