# 001 — Sign of an integer

Implement `int sign(int value)` in `001.c`.

Return `-1` when `value` is negative, `1` when it is positive, and `0` when it
is zero. No branches are required: the expression `(value > 0) - (value < 0)`
works because comparisons in C evaluate to `0` or `1`.

Examples: `sign(-42)` → `-1`; `sign(0)` → `0`; `sign(7)` → `1`.

> Read: Beej's Guide to C, §3.2.5 Conditional Operators and §3.2.6 Boolean
> Operators — https://beej.us/guide/bgc/html/split/variables-and-statements.html

Run `make run N=1`; check with `make test N=1`.
