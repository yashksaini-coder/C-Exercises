# 078 — Binary min-heap

Implement `int heap_push(MinHeap *heap, int value)` and
`int heap_pop(MinHeap *heap, int *out)` in `078.c`.

`typedef struct { int items[64]; size_t count; } MinHeap;` — a complete
binary tree stored in an array. For the node at index `i`, its parent is
`(i - 1) / 2` and its children are `2i + 1` and `2i + 2`. The heap
property: every parent is `<=` its children, so `items[0]` is always the
minimum. The caller zero-initialises the heap.

Contract:

- `heap_push(h, v)`: `-1` when `count == 64`. Otherwise append `v` at
  index `count`, increment `count`, then **sift up**: while the node is
  smaller than its parent, swap them. Return `0`.
- `heap_pop(h, out)`: `-1` when `count == 0` (`*out` untouched).
  Otherwise write `items[0]` to `*out`, move the last element to index
  `0`, decrement `count`, then **sift down**: while a child is smaller
  than the node, swap with the *smaller* child. Return `0`.

Both operations are O(log n). The usual first-attempt bugs: sifting down
by comparing with only the left child (which breaks ordering when the
right child is the smaller one), and reading a child index past `count`.
Duplicates are allowed and must all come out.

Examples: push `5, 3, 8, 1` then pop four times → `1, 3, 5, 8`; pop an
empty heap → `-1`; push 64 values then a 65th → `-1`; pushing
`{2, 2, 1, 2}` pops `1, 2, 2, 2`.

> Read: Beej's Guide to C, §6 Arrays — https://beej.us/guide/bgc/html/split/arrays.html
> The heap is the structure behind priority queues, Dijkstra and heapsort;
> interviewers want the index arithmetic from memory.
