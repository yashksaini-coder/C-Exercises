# 032 — Run-length encoding

Implement `int compress_runs(const char *s, char *destination, size_t capacity)` in `032.c`.

Encode `s` into `destination`: each maximal run of the same byte becomes the
byte followed by the run length in decimal, except that a run of length `1`
is written as the bare byte. `"aaabccdddd"` → `"a3bc2d4"`. Return the
length of the encoded string (excluding the NUL), or `-1` if the encoded
text plus its NUL does not fit in `capacity` bytes. On `-1`, `destination`
contents are unspecified except that `destination[0] == '\0'` when
`capacity > 0`; `capacity == 0` returns `-1` and writes nothing. `""`
encodes to `""` and returns `0` (which needs `capacity >= 1`).

Runs may be long: `"aaaaaaaaaaaa"` (12 a's) → `"a12"`, so the count can be
several digits. Write the count digits yourself (`int_to_string` from
exercise 031, copied in as a helper, is the natural tool; a small
`do { ... } while` over `% 10` with a reversal also works). Digits in the
input are ordinary bytes: `"111"` → `"13"`. The encoding is not required to
be reversible.

Check the capacity *before* every write, not after: with `capacity == 3`,
`"aaab"` must return `-1` without having written `"a3b"` past the buffer.
`SANITIZE=1` will report any overrun. The tests also pass a `capacity`
exactly equal to the output length plus one, which must succeed.

Forbidden: `sprintf`, `snprintf`, everything in `<string.h>`.

Examples (capacity 32 unless noted): `"aaabccdddd"` → `"a3bc2d4"`, `7`;
`"abc"` → `"abc"`, `3`; `""` → `""`, `0`; `"aaaaaaaaaaaa"` → `"a12"`, `3`;
`"aaabccdddd"` with capacity `7` → `-1`; with capacity `8` → `7`.
