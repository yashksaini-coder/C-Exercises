# 011 — Swap through pointers

Implement `void swap_int(int *a, int *b)` in `011.c`.

Exchange the values that `a` and `b` point to. C passes arguments by value,
so a function receiving two `int`s cannot change the caller's variables; it
has to receive their *addresses* and write through them with `*a` and `*b`.

Both pointers are always valid (never `NULL`). They may point to the same
object: `swap_int(&x, &x)` must leave `x` unchanged — this rules out the
XOR trick, which zeroes `x` in that case. Use a temporary. No library calls.

Examples: `x = 1, y = 2; swap_int(&x, &y)` → `x == 2, y == 1`;
`x = 5; swap_int(&x, &x)` → `x == 5`; swapping `v[0]` and `v[2]` of
`{1, 2, 3}` → `{3, 2, 1}`.

> [!TIP]
> Read: Beej's Guide to C, §5.4 Dereferencing and §5.5 Passing Pointers as
> Arguments — https://beej.us/guide/bgc/html/split/pointers.html
> This is the canonical "why pointers exist" example.

Run `make run N=11`; check with `make test N=11`.
