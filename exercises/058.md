# 058 — Variadic packer (BGNET pack)

Implement `size_t pack(unsigned char *buffer, const char *format, ...)` in
`058.c`.

Serialize the variadic arguments into `buffer` according to `format`, one
character per argument, all multi-byte integers in big-endian (network)
order. Return the total number of bytes written. This is a simplified
version of the `pack()` from Beej's Guide to Network Programming §7.5,
without the floating-point formats.

| char | argument type (what `va_arg` must fetch) | bytes written                                      |
| ---- | ---------------------------------------- | -------------------------------------------------- |
| `c`  | `int`                                    | 1: the low 8 bits                                  |
| `h`  | `int`                                    | 2: the low 16 bits, big-endian                     |
| `l`  | `uint32_t`                               | 4: big-endian                                      |
| `q`  | `uint64_t`                               | 8: big-endian                                      |
| `s`  | `const char *`                           | 2: `strlen` as 16-bit big-endian, then the bytes (no NUL) |

Walk `format` with `va_start`/`va_arg`/`va_end` from `<stdarg.h>`. The
types in the table are the types you pass to `va_arg`: default argument
promotion turns `char` and `short` into `int`, which is why `c` and `h`
fetch `int`, and why fetching `uint8_t` from `va_arg` is undefined. For
`l` and `q` the caller must pass exactly `uint32_t`/`uint64_t` values (the
tests do). Ignore unknown format characters (write nothing, consume no
argument). An empty format writes `0` bytes.

Write each integer byte by byte, most significant first, exactly like
`write_u32_be` (056) — you may call `write_u32_be` for `l`. Strings
longer than 65535 bytes are not required to work. The caller guarantees
`buffer` is large enough.

Forbidden: `htons`/`htonl`, `memcpy` of raw integers, `sprintf`.

Examples: `pack(b, "c", 0x41)` → `1` byte: `41`;
`pack(b, "h", 0x1234)` → `2` bytes: `12 34`;
`pack(b, "lq", (uint32_t)0xDEADBEEF, (uint64_t)1)` → `12` bytes:
`DE AD BE EF 00 00 00 00 00 00 00 01`;
`pack(b, "s", "hi")` → `4` bytes: `00 02 68 69`;
`pack(b, "chs", -1, 258, "")` → `5` bytes: `FF 01 02 00 00`.
