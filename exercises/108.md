# 108 — Two sum

Implement `bool two_sum(const int *values, size_t count, int target, size_t *i, size_t *j)`
in `108.c`.

Find two *different* positions `i < j` such that `values[i] + values[j] ==
target`. Store them in `*i` and `*j` and return `true`. Return `false`
(leaving `*i` and `*j` untouched) when no pair sums to `target`, including
when `count < 2`. The same element may not be used twice: `{3}` with
target `6` is `false`, but `{3, 3}` is `true` with `0, 1`.

When several pairs work, return the one with the smallest `i`, and for
that `i` the smallest `j`. Values may be negative, and the sum may
overflow `int`: compare in `long` (or `long long`) so `{INT_MAX, 1}` with
target `INT_MIN` is correctly `false` rather than undefined behaviour.

The O(n²) double loop is accepted here: `for i, for j > i`. Mention in a
comment how you would do it in O(n) with a hash map from value to index
(exercise 075 has one), since that is the follow-up every interviewer asks.
No sorting (it loses the original indices unless you carry them along).

Examples: `two_sum({2, 7, 11, 15}, 4, 9)` → `true`, `i = 0`, `j = 1`;
`two_sum({3, 2, 4}, 3, 6)` → `true`, `1, 2` (not `0, 0`);
`two_sum({3, 3}, 2, 6)` → `true`, `0, 1`; `two_sum({1, 2, 3}, 3, 7)` →
`false`; `two_sum({5}, 1, 10)` → `false`.
