# 101 — DNS via getaddrinfo

Implement `int resolve_ipv4(const char *hostname, char *destination, size_t capacity)`
in `101.c`.

Look up `hostname` and write its first IPv4 address into `destination` as a
dotted-quad string (`"93.184.216.34"`), NUL-terminated. Return `0` on
success and `-1` on failure.

Steps: `getaddrinfo(hostname, NULL, &hints, &results)` with
`hints.ai_family = AF_INET` and `hints.ai_socktype = SOCK_STREAM` (without
a socktype you get three copies of every address, one per protocol). Take
the first result, cast `ai_addr` to `struct sockaddr_in *`, and convert
`sin_addr` with `inet_ntop(AF_INET, ..., destination, capacity)`.
`freeaddrinfo` on every path.

Failure cases, all `-1`: `hostname` or `destination` is `NULL`; the name
does not resolve (`getaddrinfo` returns non-zero; print nothing); the
result list is empty; `capacity` is smaller than the string needs
(`inet_ntop` returns `NULL` with `ENOSPC`; `INET_ADDRSTRLEN`, 16, always
suffices). On failure leave `destination` unspecified.

A numeric string such as `"127.0.0.1"` is a valid hostname: `getaddrinfo`
parses it without touching DNS. The tests only use `"127.0.0.1"` and
`"localhost"`, so they work offline. `gethostbyname` is forbidden
(obsolete, IPv4-only, not thread-safe).

Examples: `resolve_ipv4("127.0.0.1", buf, 16)` → `0`, `"127.0.0.1"`;
`resolve_ipv4("localhost", buf, 16)` → `0` and a string beginning `"127."`;
`resolve_ipv4("127.0.0.1", buf, 8)` → `-1`;
`resolve_ipv4("no.such.host.invalid", buf, 16)` → `-1` (the `.invalid` TLD
is reserved to never resolve).
