# 029 — Count words

Implement `size_t count_words(const char *s)` in `029.c`.

Return the number of words in `s`, where a word is a maximal run of
non-whitespace characters and whitespace is anything `isspace` accepts
(space, `\t`, `\n`, `\v`, `\f`, `\r`). Any amount of whitespace separates
words; leading and trailing whitespace does not create words. `""` and an
all-whitespace string contain `0` words. Punctuation is not special:
`"a,b"` is one word.

Keep a flag `in_word`. Scan the bytes: on a non-space while `!in_word`,
count a word and set the flag; on a space clear it. Do not count spaces and
add one — that is the first-attempt bug that turns `"  a  b  "` into `5`.
Pass `isspace` an `unsigned char`.

Forbidden: `strtok`, `strlen`, everything in `<string.h>`. `<ctype.h>` is
allowed.

Examples: `"hello world"` → `2`; `"  leading and   trailing  "` → `3`;
`"one"` → `1`; `""` → `0`; `" \t\n "` → `0`; `"a,b c.d"` → `2`.

> Read: Beej's Guide to C, §21 Characters and Strings II —
> https://beej.us/guide/bgc/html/split/characters-and-strings-ii.html
