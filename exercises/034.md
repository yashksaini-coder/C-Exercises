# 034 — Nested structs

Implement `double rect_area(Rect r)` and `bool rect_contains(Rect r, Point p)`
in `034.c`.

`Rect` is `typedef struct { Point origin; double width, height; } Rect;` —
a struct whose first member is itself a struct. `origin` is the corner with
the smallest `x` and `y`; the rectangle extends `width` to the right and
`height` upward. Nested members chain with the dot: `r.origin.x`.

`rect_area` returns `width * height`. `rect_contains` returns `true` when
`p` lies inside the rectangle *or on its edge* (inclusive on all four sides):
`origin.x <= p.x <= origin.x + width` and the same for `y`. A rectangle with
zero width or height still contains the points on its (degenerate) edge.

Assume `width` and `height` are non-negative; you do not need to normalize
negative sizes. No library functions are needed.

Examples: with `r = {{0,0}, 10, 5}`: `rect_area(r)` → `50`;
`rect_contains(r, {5,2.5})` → `true`; `rect_contains(r, {10,5})` → `true`
(corner, inclusive); `rect_contains(r, {10.0001,5})` → `false`;
`rect_contains(r, {-0.5,2})` → `false`.
