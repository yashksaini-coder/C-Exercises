# 111 — Longest common prefix

Implement `size_t longest_common_prefix(const char *const *strings, size_t count, char *out, size_t capacity)`
in `111.c`.

Find the longest string that every one of the `count` strings starts
with. Write it into `out`, NUL-terminated and truncated to `capacity - 1`
characters if it does not fit, and return the *full* prefix length (not
the truncated one), so a caller can detect truncation by comparing the
return value with `capacity`.

Edge cases: `count == 0` → prefix length `0` and `out` is `""`. Any empty
string in the set → `0`. `capacity == 0` → write nothing, still return
the length. A single string is its own prefix. Comparison is
case-sensitive and byte-wise.

Approach: take the first string as the candidate; for each other string,
shorten the candidate length to the number of leading characters that
match. Stop early when it reaches `0`. No `malloc`, no `strncmp` (it is a
one-liner with it; the loop is the point), `strlen` is fine.

Examples: `{"flower", "flow", "flight"}` → `2`, `out` is `"fl"`;
`{"dog", "racecar", "car"}` → `0`, `""`; `{"interview"}` → `9`,
`"interview"`; `{"abc", "abc"}` → `3`; `{"abcdef", "abcxyz"}` with
`capacity` 3 → returns `3`, `out` is `"ab"`; `count` 0 → `0`, `""`.
