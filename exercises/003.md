# 003 — Leap years

Implement `bool is_leap_year(int year)` in `003.c`.

Apply the Gregorian rule: a year is a leap year when it is divisible by 4,
*except* that century years (divisible by 100) are not leap years *unless*
they are also divisible by 400. So 1996, 2000 and 2400 are leap years; 1900,
2100 and 2023 are not. Treat every `int` as a proleptic Gregorian year;
negative years and year 0 follow the same rule (`0` is divisible by 400, so
`is_leap_year(0)` is `true`).

Use the `%` operator and the boolean operators `&&`, `||`, `!`. Do not use
tables, floating point or any library call. The classic first-attempt bug is
checking only `year % 4 == 0`, which calls 1900 a leap year.

Examples: `is_leap_year(1996)` → `true`; `is_leap_year(1900)` → `false`;
`is_leap_year(2000)` → `true`; `is_leap_year(2023)` → `false`.
