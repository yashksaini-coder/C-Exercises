# 041 — Duplicate a string

Implement `char *my_strdup(const char *s)` in `041.c`.

Return a newly allocated copy of `s`, including the terminating NUL, that the
caller owns and must release with `free()`. Return `NULL` when `s` is `NULL`
or when `malloc` fails. An empty string yields a one-byte allocation holding
`'\0'`.

This is the simplest "returns owned memory" function in C and the pattern
every later exercise builds on: measure, allocate `length + 1` (the classic
first-attempt bug is forgetting the `+ 1`), copy, hand the pointer back and
document who frees it. The copy must be independent: changing the source
afterwards must not affect the duplicate.

Allowed: `malloc`, `strlen`, `memcpy`/`strcpy` (or your `my_strlen` and
`my_strcpy`). Forbidden: `strdup`, `strndup` — they are what you are
implementing.

Examples: `my_strdup("hello")` → `"hello"` (a different pointer from the
literal); `my_strdup("")` → `""`; `my_strdup(NULL)` → `NULL`.
