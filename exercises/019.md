# 019 — Predicates as callbacks

Implement `size_t count_matching(const int *values, size_t count, bool (*predicate)(int))` in `019.c`.

Return how many elements of `values[0..count)` make `predicate` return
`true`. `count == 0` returns `0` without calling the predicate (`values` may
be `NULL` then). `predicate` is never `NULL` and must be called exactly once
per element — one test uses a predicate with a side effect to check that.

A *predicate* is a function returning `bool`; the parameter
`bool (*predicate)(int)` is a pointer to one. This is the shape of every
"filter" or "count if" API in C: the caller supplies the policy, the
function supplies the loop. Do not add a `break`: you are counting, not
searching, so the whole array must be visited. No library calls.

Examples: `{1, 2, 3, 4, 5, 6}` with `is_even` → `3`; `{-3, -1, 0, 2}` with
`is_negative` → `2`; `{1, 3, 5}` with `is_even` → `0`; `count == 0` → `0`.
