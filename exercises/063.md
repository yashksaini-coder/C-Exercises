# 063 — Generic code with void *

Implement `const void *generic_max(const void *base, size_t count, size_t size, Comparator compare)`
in `063.c`, where `typedef int (*Comparator)(const void *a, const void *b);`.

`base` points at an array of `count` elements, each `size` bytes, of a type
this function knows nothing about. `compare(a, b)` returns negative, zero or
positive like `strcmp`. Return a pointer to the largest element — the
*first* one if several compare equal. Return `NULL` when `count` is `0`.

C has no templates. Generic code works on raw bytes: you cannot index a
`void *`, so cast `base` to `const unsigned char *` (or `const char *`) and
compute the address of element `i` as `bytes + i * size`. Pass those
addresses to the comparator, which casts them back to the real type. This is
how `qsort` and `bsearch` are written, and exercises 064 and 065 build on it.

Do not allocate, do not modify the array, do not assume any element type.
The comparator from 035 (`compare_students`) is a valid `Comparator`.

Examples: ints `{3, 9, 2, 9}` with an int comparator → pointer to index `1`
(the first `9`); doubles `{-1.5, -0.5, -2.0}` → pointer to `-0.5`; strings
`{"pear", "apple", "zoo"}` compared with `strcmp` → pointer to `"zoo"`;
`count == 0` → `NULL`.
