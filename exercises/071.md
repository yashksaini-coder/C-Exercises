# 071 — Singly linked list

Implement `int list_push_back(IntNode **head, int value)`,
`size_t list_length(const IntNode *head)` and `void list_free(IntNode *head)`
in `071.c`.

`typedef struct IntNode { int value; struct IntNode *next; } IntNode;` A
list is just a pointer to its first node; the empty list is `NULL`. There
is no separate list struct, which is why `list_push_back` takes an
`IntNode **`: appending to an empty list must change the caller's `head`
variable itself, and a `IntNode *` parameter could not do that.

Contract:

- `list_push_back(&head, v)` allocates one node with `malloc`, sets its
  value and `next = NULL`, and links it after the current last node (or
  makes it the head when the list is empty). Returns `0`, or `-1` if
  allocation fails (the list is unchanged).
- `list_length(head)` returns the number of nodes; `NULL` → `0`.
- `list_free(head)` frees every node; `list_free(NULL)` is a no-op. Save
  `next` **before** freeing a node — reading `node->next` after
  `free(node)` is a use-after-free that `SANITIZE=1` catches.

Walking to the end makes `list_push_back` O(n); that is acceptable here. No
globals, no tail pointer cached anywhere.

Examples: three pushes of `1, 2, 3` on an empty list → values `1, 2, 3` in
order, length `3`; `list_length(NULL)` → `0`; pushing onto a list of
length 1 keeps the original head node.
