# 026 — Reverse in place

Implement `void reverse_string(char *s)` in `026.c`.

Reverse the characters of the NUL-terminated string `s` in place, leaving
the terminator where it is. `""` and single-character strings are
unchanged. The string is writable (the tests pass arrays, never literals;
do the same in your playground — reversing a string literal is undefined
behaviour).

Find the end first (your own loop, or `my_strlen` from exercise 021 copied
in), then swap `s[left]` and `s[right]` while `left < right`, exactly as in
`array_reverse` (013). Two things to get right: `right` starts at
`length - 1`, not `length`, or you swap the NUL into the front and the
string becomes empty; and with `size_t` indices, `length - 1` for an empty
string is `SIZE_MAX`, so return early when `length < 2`.

Forbidden: `strrev` (non-standard anyway), `strlen`, everything in
`<string.h>`. No temporary buffer.

Examples: `"hello"` → `"olleh"`; `"ab"` → `"ba"`; `"a"` → `"a"`; `""` →
`""`; `"racecar"` → `"racecar"`.

> [!TIP]
> Read: Beej's Guide to C, §7.4 String Termination and §7.1 String Literals
> (why literals are read-only) — https://beej.us/guide/bgc/html/split/strings.html

Run `make run N=26`; check with `make test N=26`.
