# 005 — Primality

Implement `bool is_prime(unsigned value)` in `005.c`.

Return `true` when `value` is a prime number. `0` and `1` are not prime; `2`
is the only even prime. The parameter is `unsigned`, so every value from `0`
to `UINT_MAX` (4294967295 on this platform) is valid input.

The test calls `is_prime(4294967291)`, the largest 32-bit prime. A loop that
tries every divisor up to `value` runs four billion iterations and times out;
a loop that stops at the square root runs about 65 000 and finishes
instantly. Stop when `divisor * divisor > value` — but notice that for a
value near `UINT_MAX` the product `divisor * divisor` can wrap around in
32-bit arithmetic. Either compute the square in a `uint64_t` or write the
condition as `divisor <= value / divisor`, which never overflows. An
optional refinement: test `2` once, then only odd divisors.

No library calls (`sqrt` is forbidden; unsigned wraparound is defined but
here it gives wrong answers, which is the point).

Examples: `is_prime(2)` → `true`; `is_prime(1)` → `false`; `is_prime(97)` →
`true`; `is_prime(91)` → `false` (7 × 13); `is_prime(4294967291)` → `true`.
