# 116 — Evaluate reverse Polish notation

Implement `bool evaluate_rpn(const char *expression, long *result)` in `116.c`.

Reverse Polish notation puts the operator after its operands: `3 4 +` is
`7`, and `3 4 + 2 *` is `14`. Evaluate with a stack: push each number;
for each operator pop two values (the *second* popped is the left
operand), apply, push the result. At the end exactly one value must
remain; that is the answer.

Contract: tokens are separated by one or more spaces (leading and
trailing spaces allowed). A number token is an optional `-` followed by
one or more decimal digits, and fits in `long`. Operators are `+`, `-`,
`*`, `/`. Division is C integer division (truncates toward zero:
`-7 / 2` is `-3`). Store the answer in `*result` and return `true`.

Return `false`, leaving `*result` unspecified, on any error:

- a token that is neither a number nor an operator (`"3 x +"`, `"3.5"`,
  `"+-"`);
- stack underflow: an operator with fewer than two values on the stack
  (`"3 +"`, `"+"`);
- leftover operands at the end (`"1 2"`), or no tokens at all (`""`,
  `"   "`);
- division by zero (`"1 0 /"`);
- more than 256 values on the stack at once (the stack is a fixed
  `long stack[256]`; overflowing it is an error, not UB).

Use `strtol` with its `end` pointer to parse numbers if you like (check
that it consumed the whole token), or parse by hand. No `malloc`, no
global state, no `strtok` (it would modify the `const` input).

Examples: `"3 4 + 2 *"` → `true`, `14`; `"5 1 2 + 4 * + 3 -"` → `14`;
`"-7 2 /"` → `-3`; `"2 3 4 * +"` → `14`; `"1 +"` → `false`; `"1 2"` →
`false`; `"1 0 /"` → `false`; `"42"` → `true`, `42`.
