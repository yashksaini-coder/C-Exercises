# 002 — Largest of three

Implement `int max_of_three(int a, int b, int c)` in `002.c`.

Return the largest of the three values. Ties are fine: if two or three
arguments are equal and largest, return that value. Any `int` is valid input,
including `INT_MIN` and `INT_MAX`.

Use plain comparisons (`if`, or the `?:` operator). Do not sort, do not reach
for a library, and do not use arithmetic tricks such as `(a + b + |a - b|) / 2`:
they overflow for large magnitudes. The exercise teaches that the comparison
chain itself is the idiom: keep a running `best` and compare each candidate
against it.

Examples: `max_of_three(1, 2, 3)` → `3`; `max_of_three(9, 4, 7)` → `9`;
`max_of_three(-5, -2, -9)` → `-2`; `max_of_three(INT_MAX, INT_MIN, 0)` →
`INT_MAX`.

> [!TIP]
> Read: Beej's Guide to C, §3.4 `if`-`else` and §3.2.5 Conditional Operators —
> https://beej.us/guide/bgc/html/split/variables-and-statements.html

Run `make run N=2`; check with `make test N=2`.
