# 017 — Two-dimensional arrays

Implement `void matrix_transpose(size_t n, int matrix[n][n])` in `017.c`.

Transpose the `n × n` matrix in place: after the call `matrix[i][j]` holds
what `matrix[j][i]` held before. `n == 0` and `n == 1` are no-ops (for
`n == 0` the pointer may be `NULL`).

The parameter uses C99 variable-length-array syntax: `int matrix[n][n]`
tells the compiler the row length is `n`, so `matrix[i][j]` indexes
correctly for any `n`. A 2-D array is stored row-major — row 0's `n`
elements, then row 1's — and `matrix[i][j]` is just element `i * n + j` of
that block. The caller passes an ordinary `int m[3][3]` (or a pointer into a
flat `int *` block, cast to `int (*)[n]`).

Swap each pair *once*: loop `i` over all rows and `j` from `i + 1` only.
Looping `j` over all columns swaps every pair twice and returns the original
matrix, which is the standard first-attempt bug. No temporary matrix, no
`<string.h>`.

Examples: `[[1, 2], [3, 4]]` → `[[1, 3], [2, 4]]`;
`[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → `[[1, 4, 7], [2, 5, 8], [3, 6, 9]]`;
`[[5]]` → `[[5]]`; a symmetric matrix is unchanged.

> Read: Beej's Guide to C, §6.7 Multidimensional Arrays —
> https://beej.us/guide/bgc/html/split/arrays.html
> and §6.6.4 Passing Multidimensional Arrays to Functions — same page.
