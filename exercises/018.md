# 018 — Function pointers

Implement `void apply_each(int *values, size_t count, int (*transform)(int))` in `018.c`.

Replace every element with the result of calling `transform` on it:
`values[i] = transform(values[i])` for each `i` in `[0, count)`. `count == 0`
is a no-op (then `values` may be `NULL`). `transform` is never `NULL`.

`int (*transform)(int)` declares a pointer to a function taking an `int`
and returning an `int`. The caller passes a function name (`apply_each(v, n,
square)`), and you call it as `transform(x)`, or equivalently
`(*transform)(x)`. Nothing is known about what the function does: apply it
exactly once per element, in index order, and do not call it when
`count == 0`. One test uses a transform that counts its own calls, so an
extra or missing call fails. No library calls.

Examples: `{1, 2, 3}` with `square` → `{1, 4, 9}`; `{1, -2, 3}` with
`negate` → `{-1, 2, -3}`; `{5}` with `identity` → `{5}`; `count == 0` →
`transform` is never called.
