# 059 — Variadic unpacker

Implement `size_t unpack(const unsigned char *buffer, const char *format, ...)`
in `059.c`.

The inverse of `pack` (058): read fields from `buffer` according to
`format` and store each through the pointer argument that follows. Return
the number of bytes consumed. Same format characters, same big-endian
encoding; the arguments are now *pointers*:

| char | argument type        | bytes read | stored value                                   |
| ---- | -------------------- | ---------- | ---------------------------------------------- |
| `c`  | `int *`              | 1          | the byte as a **signed** 8-bit value (`0xFF` → `-1`) |
| `h`  | `uint16_t *`         | 2          | big-endian 16-bit                              |
| `l`  | `uint32_t *`         | 4          | big-endian 32-bit                              |
| `q`  | `uint64_t *`         | 8          | big-endian 64-bit                              |
| `s`  | `char *`             | 2 + length | the string, NUL-terminated by you              |

For `s`, read the 16-bit length, copy that many bytes into the caller's
buffer, and append `'\0'`; assume the caller's buffer is large enough. For
`c`, convert without relying on `char` being signed: `v = byte; if (v >
127) v -= 256;`. Reassemble multi-byte integers from bytes exactly as
`read_u32_be` (055) does — cast each byte to the wide unsigned type
*before* shifting, especially for `q`, where `byte << 56` on an `int` is
undefined. Unknown format characters are skipped without consuming
anything.

Every value that `pack` writes must come back unchanged. The tests feed
`unpack` literal byte arrays in `pack`'s layout and check it recovers the
values, so you need not finish 058 first; the playground `main` is a good
place to round-trip through both once you have.

Forbidden: `ntohs`/`ntohl`, `memcpy` of raw integers from the buffer,
`sscanf`.

Examples: `unpack({0x41}, "c", &i)` → `1`, `i == 0x41`;
`unpack({0xFF}, "c", &i)` → `1`, `i == -1`;
`unpack({0x12,0x34}, "h", &h)` → `2`, `h == 0x1234`;
`unpack({0xDE,0xAD,0xBE,0xEF, 0,0,0,0,0,0,0,1}, "lq", &l, &q)` → `12`,
`l == 0xDEADBEEF`, `q == 1`;
`unpack({0x00,0x02,'h','i'}, "s", text)` → `4`, `text == "hi"`.
