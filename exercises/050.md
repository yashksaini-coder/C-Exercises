# 050 — Fixed-size block pool

Implement `int pool_init(Pool *pool, size_t block_size, size_t block_count)`,
`void *pool_get(Pool *pool)`, `void pool_put(Pool *pool, void *block)` and
`void pool_free(Pool *pool)` in `050.c`.

`Pool` is
`typedef struct { unsigned char *storage; void *free_list; size_t block_size, block_count; } Pool;`.
A pool allocator hands out fixed-size blocks in O(1) with no fragmentation
and no per-block header. The trick: a block that is *free* is not being
used for anything, so you can store the free-list `next` pointer **inside
the block itself**. That is an *intrusive* free list, and it is why
`block_size` must be at least `sizeof(void *)` and aligned for a pointer.

- `pool_init`: round `block_size` up to a multiple of `sizeof(void *)`
  and to at least `sizeof(void *)`; `malloc` one `storage` block of
  `block_size * block_count` bytes (check the multiplication for overflow);
  then walk the blocks and thread them into a singly linked list: write
  the address of block `i+1` into the first `sizeof(void *)` bytes of block
  `i` (use `memcpy` or `*(void **)block`), the last block gets `NULL`, and
  `free_list` points at block `0`. Store the rounded `block_size` and
  `block_count`. Return `0` on success, `-1` on failure, `NULL` pool, or
  `block_count == 0`.
- `pool_get`: pop the head of `free_list` and return it; `NULL` when the
  list is empty. Do not allocate more — the pool is fixed.
- `pool_put`: push `block` back onto the head of `free_list`. `NULL` is a
  no-op. You may assume `block` came from this pool.
- `pool_free`: `free(storage)` and zero every field.

Because `storage` is one allocation, every block lives at
`storage + i * block_size`; the tests check that returned pointers are
inside that range and are distinct.

Allowed: `malloc`, `free`, `memcpy`. Forbidden: a separate array of
"is-used" flags or any per-block metadata outside the blocks (that
defeats the intrusive design).

Examples: `pool_init(&p, 12, 3)` → `block_size == 16` (rounded up on a
64-bit system), three `pool_get` calls return three distinct non-NULL
blocks, a fourth returns `NULL`; `pool_put(&p, second)` then `pool_get(&p)`
→ `second` (LIFO); `pool_init(&p, 1, 4)` → `block_size == sizeof(void *)`.
