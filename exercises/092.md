# 092 — host:port and [v6]:port

Implement `int parse_host_port(const char *s, char *host, size_t host_capacity, uint16_t *port)`
in `092.c`.

Split an endpoint string into a host and a port. Two forms are valid:

- `host:port` — everything before the *last* colon is the host, everything
  after it is the port: `"example.com:8080"` → host `"example.com"`, port
  `8080`; `"127.0.0.1:80"` → `"127.0.0.1"`, `80`.
- `[v6]:port` — an IPv6 literal in brackets, because the address itself
  contains colons: `"[::1]:443"` → host `"::1"` (brackets stripped), port
  `443`. The `]` must be followed immediately by `:`.

Copy the host into `host` NUL-terminated and store the port in `*port`;
return `0`. Return `-1` and leave the outputs unspecified when: there is no
colon or no port after it (`"example.com"`, `"example.com:"`); the host is
empty (`":80"`, `"[]:80"`); the port has a non-digit (`"host:80a"`,
`"host:-1"`); the port exceeds `65535` (`"host:65536"`; check while
accumulating so `"host:99999999999"` cannot wrap); the bracket form is not
closed (`"[::1:443"`); or the host does not fit in `host_capacity` including
its NUL. A port of `0` is valid.

Use `strrchr` to find the last colon, or walk the string yourself. No
`sscanf`, `strtol`, `atoi` or `getaddrinfo`.

Examples: `"example.com:8080"` → `0`, `"example.com"`, `8080`;
`"[::1]:443"` → `0`, `"::1"`, `443`; `"example.com"` → `-1`;
`"host:65536"` → `-1`; `"example.com:80"` with `host_capacity` 8 → `-1`.

> [!TIP]
> Read: Beej's Guide to Network Programming, §3.1 IP Addresses (why IPv6
> literals need brackets) —
> https://beej.us/guide/bgnet/html/split-wide/ip-addresses-structs-and-data-munging.html
> Every service that takes a `--listen` flag needs this; the IPv6 case is the
> part most candidates forget.
