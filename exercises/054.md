# 054 — Set and clear a bit

Implement `uint32_t bit_set(uint32_t value, unsigned index, bool on)` in
`054.c`.

Return `value` with bit number `index` (0 = least significant, 31 = most
significant) set to `1` when `on` is `true` and cleared to `0` when `on` is
`false`; all other bits are unchanged. `index` is in `0..31`; for an
`index >= 32` return `value` unchanged (shifting by 32 or more is undefined
behavior in C, so never let it reach the shift).

The two idioms: set with `value | (1u << index)`, clear with
`value & ~(1u << index)`. Write the mask as `1u` or `UINT32_C(1)`, not `1`:
`1 << 31` is a *signed* int overflow and therefore undefined. This is the
single most common bug in bit manipulation code.

Allowed: nothing else needed. No lookup tables.

Examples: `bit_set(0, 0, true)` → `1`; `bit_set(0, 31, true)` →
`0x80000000`; `bit_set(0xFF, 3, false)` → `0xF7`; `bit_set(0xF7, 3, true)`
→ `0xFF`; `bit_set(5, 0, true)` → `5` (already set); `bit_set(5, 32, true)`
→ `5` (out of range, unchanged).
