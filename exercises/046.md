# 046 — Arena allocator with alignment

Implement `int arena_init(Arena *arena, size_t capacity)`,
`void *arena_alloc(Arena *arena, size_t size, size_t alignment)` and
`void arena_free(Arena *arena)` in `046.c`.

`Arena` is `typedef struct { unsigned char *base; size_t capacity, used; } Arena;`.
An arena (also "bump allocator" or "region") is the simplest allocator
there is: one big block, a cursor, and no per-object `free`. You hand out
slices by bumping the cursor and release everything at once. It is how
compilers, parsers and game frames allocate thousands of small objects
cheaply.

- `arena_init` allocates `capacity` bytes with `malloc`, sets `base`,
  `capacity`, and `used = 0`. Return `0` on success, `-1` on failure (or
  `NULL` arena). `capacity == 0` is allowed: it succeeds and every
  allocation then fails (`malloc(0)` may legally return `NULL`, so request
  at least one byte in that case).
- `arena_alloc` first rounds `used` **up** to the next multiple of
  `alignment` (a power of two: `1, 2, 4, 8, 16, …`; the expression
  `(used + alignment - 1) & ~(alignment - 1)` does it without division),
  then checks whether `aligned_start + size <= capacity`. If it fits,
  return `base + aligned_start` and set `used = aligned_start + size`. If
  it does not fit, return `NULL` and leave `used` unchanged — the arena
  never grows and never moves, which is exactly why pointers into it stay
  valid. Treat `alignment == 0` as `1`. A `size` of `0` returns a valid
  (aligned) pointer and consumes nothing beyond the padding.
- `arena_free` frees `base` and zeroes all fields; safe on a zeroed arena
  or `NULL`.

Beware the overflow in `aligned_start + size` for huge `size`; checking
`size > capacity - aligned_start` avoids it.

Allowed: `malloc`, `free`. Nothing from `<stdalign.h>` is required.

Examples: `arena_init(&a, 64)`; `arena_alloc(&a, 1, 1)` → `base + 0`,
`used == 1`; `arena_alloc(&a, 4, 8)` → `base + 8`, `used == 12`;
`arena_alloc(&a, 100, 1)` → `NULL`, `used` still `12`;
`arena_alloc(&a, 52, 4)` → `base + 12`, `used == 64`;
`arena_alloc(&a, 1, 1)` → `NULL` (full).
