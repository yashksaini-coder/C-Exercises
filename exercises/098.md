# 098 — Client connect

Implement `int tcp_connect(const char *host, const char *port)` in `098.c`.

Open a TCP connection to `host` (a hostname or a dotted-quad such as
`"127.0.0.1"`) at `port` (a decimal string) and return the connected file
descriptor, or `-1` if no connection could be made.

The shape is Beej's client:

1. `getaddrinfo(host, port, &hints, &results)` with `hints.ai_family =
   AF_UNSPEC` and `hints.ai_socktype = SOCK_STREAM`. No `AI_PASSIVE`; this is
   the connecting side.
2. For each result: `socket()`, then `connect()`. On success, stop. On
   failure, `close` the socket and try the next address (a host with several
   addresses is exactly why the list exists).
3. `freeaddrinfo(results)` on every path.

Return `-1` when `host` or `port` is `NULL`, when `getaddrinfo` fails (an
unparseable address like `"256.256.256.256"`), or when every `connect`
fails (nothing is listening). The caller owns the descriptor.

Allowed: everything in `<netdb.h>` and `<sys/socket.h>`. Do not hand-fill a
`struct sockaddr_in` and do not use `gethostbyname` (obsolete, not
thread-safe).

Examples: with a listener on `127.0.0.1` at port `P`,
`tcp_connect("127.0.0.1", "P")` → a descriptor `>= 0`; bytes written to it
arrive at the socket the listener `accept()`s; `tcp_connect("127.0.0.1",
"P")` after the listener is closed → `-1`;
`tcp_connect("256.256.256.256", "80")` → `-1`; `tcp_connect(NULL, "80")`
→ `-1`.
