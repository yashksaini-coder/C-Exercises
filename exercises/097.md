# 097 — getaddrinfo, socket, bind, listen

Implement `int tcp_listen(const char *port)` in `097.c`.

Create a TCP socket that listens on every local interface on the given
`port` (a decimal string such as `"8080"`, or `"0"` to let the kernel pick a
free port) and return its file descriptor, or `-1` on failure.

Do it the way Beej's server does:

1. `getaddrinfo(NULL, port, &hints, &results)` with `hints.ai_family =
   AF_INET`, `hints.ai_socktype = SOCK_STREAM`, `hints.ai_flags = AI_PASSIVE`
   (`AI_PASSIVE` plus a `NULL` node means "all my addresses").
2. Walk the result list. For each entry: `socket()`, set `SO_REUSEADDR` with
   `setsockopt` (so a restarted server does not get `EADDRINUSE` while the
   old connections sit in `TIME_WAIT`), `bind()`. On the first success,
   stop; on failure, `close` that socket and try the next entry.
3. `freeaddrinfo(results)` on every path, including failure.
4. `listen(fd, 16)`; if that fails, `close` and return `-1`.

Using `AF_INET` rather than `AF_UNSPEC` keeps the tests deterministic on
machines without IPv6. The caller owns the returned descriptor and closes
it. Return `-1` for a `NULL` or non-numeric port, or when `getaddrinfo`,
`socket`, `bind` or `listen` fail.

Allowed: everything in `<netdb.h>` and `<sys/socket.h>`. Do not hand-fill a
`struct sockaddr_in` (the point is learning `getaddrinfo`).

Examples: `tcp_listen("0")` → a descriptor `>= 0` on which `getsockname`
reports a non-zero port, and a `connect()` to `127.0.0.1` on that port
succeeds and is returned by `accept()`; `tcp_listen("notaport")` → `-1`;
`tcp_listen(NULL)` → `-1`; two calls to `tcp_listen("0")` → two different
descriptors on two different ports.
