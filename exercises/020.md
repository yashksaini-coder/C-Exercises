# 020 — Two-pointer compaction

Implement `size_t remove_duplicates_sorted(int *values, size_t count)` in `020.c`.

`values[0..count)` is sorted in non-decreasing order. Remove consecutive
duplicates in place so that the first `new_length` elements are the distinct
values in their original order, and return `new_length`. Elements beyond
`new_length` are unspecified (the tests do not look at them). `count == 0`
returns `0` (`values` may be `NULL`); `count == 1` returns `1`.

Use the two-pointer (read/write) technique: `write` is the number of
distinct elements kept so far; for each `read` index from `1`, if
`values[read] != values[write - 1]`, copy it to `values[write]` and advance
`write`. This is O(count) time and O(1) space. Do not shift the tail left on
every duplicate (O(count²)) and do not allocate. The classic first-attempt
bug is comparing `values[read]` with `values[read - 1]` after the array has
already been partially overwritten; compare against the last *written*
element. No library calls.

Examples: `{1, 1, 2, 3, 3, 3, 4}` → returns `4`, array starts `{1, 2, 3, 4}`;
`{2, 2, 2}` → `1`, `{2}`; `{1, 2, 3}` → `3`, unchanged; `{}` → `0`;
`{INT_MIN, INT_MIN, INT_MAX}` → `2`.
