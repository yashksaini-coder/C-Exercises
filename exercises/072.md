# 072 — Reverse a linked list

Implement `IntNode *list_reverse(IntNode *head)` in `072.c`.

Reverse the list in place and return the new head (the old last node). Do
it iteratively with three pointers — `previous`, `current`, `next` — in
O(n) time and O(1) extra space: no recursion, no allocation, no array of
nodes. Every node keeps its address; only the `next` pointers change.

The loop: save `current->next`, point `current->next` at `previous`, then
advance both `previous` and `current`. When `current` becomes `NULL`,
`previous` is the new head. The usual first-attempt bug is overwriting
`current->next` before saving it, which loses the rest of the list.

`list_reverse(NULL)` → `NULL`. A one-node list is returned unchanged. The
old head's `next` must be `NULL` afterwards, or the list has a cycle.

The tests build lists by hand and free them with their own loop, so 071 is
not a dependency; you may still use `list_push_back` in your playground
`main` if you copy it into this file.

Examples: `1 → 2 → 3` → `3 → 2 → 1`; `NULL` → `NULL`; `7` → `7`;
`1 → 2` → `2 → 1` and the returned head is the node that held `2`.
