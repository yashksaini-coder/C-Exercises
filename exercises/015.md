# 015 — Linear search with ptrdiff_t

Implement `ptrdiff_t find_index(const int *values, size_t count, int target)` in `015.c`.

Return the index of the *first* element equal to `target`, or `-1` when it
does not occur in `values[0..count)`. With `count == 0` always return `-1`
(`values` may be `NULL` then).

The return type is `ptrdiff_t` from `<stddef.h>`: the signed counterpart of
`size_t`, wide enough to hold any array index *and* `-1`. Returning `-1` as
a `size_t` would silently become `SIZE_MAX`, which is why this function
does not return `size_t`. Convert your loop index with a cast,
`return (ptrdiff_t)i;`, so the compiler does not warn about the sign change.
Print a `ptrdiff_t` with `%td`.

A linear scan is required; no sorting, no `bsearch`, no library calls.

Examples: `{4, 8, 15, 16}, target 15` → `2`; `{4, 8, 15, 16}, target 7` →
`-1`; `{5, 5, 5}, target 5` → `0`; `count == 0` → `-1`.
