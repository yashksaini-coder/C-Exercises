# 044 — Join strings into owned memory

Implement `char *string_join(const char *const *parts, size_t count, const char *separator)`
in `044.c`.

Return a newly allocated string made of `parts[0]`, `separator`, `parts[1]`,
`separator`, …, `parts[count-1]` — the separator goes *between* parts, never
at the start or end. The caller frees the result. When `count` is `0`,
return an allocated empty string `""` (not `NULL`). `separator` may be `""`;
treat a `NULL` separator the same as `""`. Return `NULL` only on allocation
failure or when `parts` is `NULL` with `count > 0`.

Do it in two passes: first add up `strlen` of every part plus
`(count - 1) * strlen(separator)` to get the exact size, allocate once
(`+ 1` for the NUL), then copy everything in. The one-pass alternative —
`realloc` on every append — is slower and harder to get right. Watch the
boundary: with `count == 1` there is no separator, and `(count - 1)` with
`count == 0` underflows `size_t`, so handle `count == 0` before the
arithmetic.

`const char *const *parts` reads inside-out: a pointer to const pointers to
const char. You cannot modify the strings or the array through it.

Allowed: `malloc`, `strlen`, `memcpy`/`strcpy`/`strcat`. Forbidden:
`asprintf`, `snprintf`-with-growth tricks.

Examples: `string_join({"a","b","c"}, 3, ", ")` → `"a, b, c"`;
`string_join({"x"}, 1, "-")` → `"x"`; `string_join({"ab","cd"}, 2, "")` →
`"abcd"`; `string_join(NULL, 0, "+")` → `""`;
`string_join({"", "", ""}, 3, "/")` → `"//"`.
