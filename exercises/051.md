# 051 — Popcount

Implement `unsigned bit_count(uint32_t value)` in `051.c`.

Return the number of bits set to `1` in `value` (the "population count" or
Hamming weight). `0` → `0`; `0xFFFFFFFF` → `32`.

The straightforward loop tests each of the 32 bits: `count += value & 1;
value >>= 1;`. Kernighan's trick does it in one iteration per *set* bit:
`value &= value - 1` clears the lowest set bit, so loop until `value` is
`0` and count the iterations. Either is fine; know both. Shift only
unsigned values — right-shifting a negative signed integer is
implementation-defined.

Forbidden: `__builtin_popcount` and friends (they compile to a single
instruction, which is what you would use in production, but not here).

Examples: `bit_count(0)` → `0`; `bit_count(1)` → `1`; `bit_count(0xFF)` →
`8`; `bit_count(0x80000000)` → `1`; `bit_count(0xFFFFFFFF)` → `32`;
`bit_count(0xA5A5A5A5)` → `16`.

> [!TIP]
> Read: Beej's Guide to C, ch. 24 Bitwise Operations —
> https://beej.us/guide/bgc/html/split/bitwise-operations.html
> Popcount and "clear the lowest set bit" are the first two bit tricks any
> interviewer expects.

Run `make run N=51`; check with `make test N=51`.
