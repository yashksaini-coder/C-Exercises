# 103 — Create and join threads

Implement `long parallel_sum(const int *values, size_t count, size_t thread_count)`
in `103.c`.

Sum `count` ints using `thread_count` POSIX threads and return the total as
a `long`. Split the array into `thread_count` contiguous slices (the last
slice takes the remainder), give each thread one slice, and let each
thread write its partial sum into *its own* field of a per-thread struct.
After `pthread_join` on every thread, add the partials up on the calling
thread.

Rules:

- `thread_count == 0` is treated as `1`. `thread_count > count` is capped
  at `count` (an empty slice is pointless). `count == 0` returns `0`
  without creating a thread.
- No shared mutable state: threads only read `values` and write their own
  struct. Do not have every thread add into one shared `long`; that is a
  data race, and the result is wrong and undefined. Do not use a mutex here
  either; the point is that disjoint data needs no lock.
- Every thread you create must be joined before you return. If
  `pthread_create` fails for thread `k`, sum thread `k`'s slice on the
  calling thread instead (or join what you have and compute the rest
  inline); never return early with threads still running.
- Use `pthread_create`/`pthread_join` from `<pthread.h>`. Beej's guide
  covers C11 `<threads.h>`, which has the same shape; jobs ask for pthreads,
  so use those. The `Makefile` already links `-lpthread`.

Examples: `parallel_sum({1, 2, 3, 4, 5}, 5, 2)` → `15`;
`parallel_sum(values, 100000, 8)` with `values[i] = i` → `4999950000`;
`parallel_sum(values, 3, 10)` → the same as with 3 threads;
`parallel_sum(NULL, 0, 4)` → `0`.
