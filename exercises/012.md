# 012 — Index of the maximum

Implement `size_t array_max_index(const int *values, size_t count)` in `012.c`.

Return the index of the largest element among `values[0..count)`. When the
maximum occurs more than once return the *first* index where it appears, so
compare with `>` (strictly greater), not `>=`. When `count` is `0` there is
no element; return `0` (the only sensible value for a `size_t`, and the
`.md` contract the tests rely on). `values` may be `NULL` only when `count`
is `0`; never read it then.

Start with `best = 0` and scan from index `1`. Do not initialise the running
maximum to `0` or to `INT_MIN` and then scan from `0`: the first works only
for non-negative arrays, and the second needs `<limits.h>` for something the
array already tells you. No library calls, no sorting.

Examples: `{3, 9, 2, 9}` → `1`; `{-5, -2, -9}` → `1`; `{7}` → `0`;
`{-1, -1, -1}` → `0`; `count == 0` → `0`.

> [!TIP]
> Read: Beej's Guide to C, §6.3 Array Initializers and §6.5 Arrays and
> Pointers — https://beej.us/guide/bgc/html/split/arrays.html
