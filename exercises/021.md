# 021 — String length

Implement `size_t my_strlen(const char *s)` in `021.c`.

Return the number of characters in `s` before its terminating `'\0'`,
exactly like `strlen`. `s` is always a valid NUL-terminated string; the
empty string `""` has length `0`. Characters are counted as bytes: a string
containing an embedded `'\0'` literal is cut short there, just as with the
real function.

A C string is just a `char` array with a NUL byte marking the end; the
length is not stored anywhere, which is why this function has to walk the
bytes. Loop until `s[i] == '\0'` (or until `*p == 0` with a moving pointer)
and count. Return `size_t`, not `int`.

Forbidden: `strlen`, `strnlen`, anything from `<string.h>`.

Examples: `my_strlen("")` → `0`; `my_strlen("hello")` → `5`;
`my_strlen("a")` → `1`; `my_strlen("ab\0cd")` → `2`.

> [!TIP]
> Read: Beej's Guide to C, §7.3 String Length and §7.4 String Termination —
> https://beej.us/guide/bgc/html/split/strings.html
