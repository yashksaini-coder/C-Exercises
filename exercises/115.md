# 115 — Add big integers as strings

Implement `int bigint_add(const char *a, const char *b, char *out, size_t capacity)`
in `115.c`.

`a` and `b` are non-negative integers written in decimal, of any length
(far beyond `uint64_t`), with no sign, no spaces, and at least one digit
each. Write their sum into `out` as a decimal string, NUL-terminated, and
return its length. Return `-1` without writing if the sum plus its NUL
would not fit in `capacity`, or if either input contains a non-digit or
is empty.

Add the way you do on paper: from the last digit of each string towards
the first, carrying. The sum has `max(len(a), len(b))` digits, plus one
when the final carry is set. A `capacity` exactly one more than the real
length must succeed, so you cannot reject on the pessimistic bound. Two
clean passes work: run the addition once without writing to learn the
exact length (final carry, and where the highest non-zero digit is), check
it against `capacity`, then run it again writing right-to-left into
exactly that many slots. Alternatively write into `out` from index
`max_len` downwards and `memmove` left at the end; then you need
`max_len + 2` bytes of capacity, which the tests do not grant for the
exact-fit case, so prefer the two-pass version.

Leading zeros in the inputs are allowed (`"007" + "1"` is `"8"`); the
output has no leading zeros except that `"0" + "0"` is `"0"`. No
`malloc`, no conversion to a machine integer (`strtoull` would overflow
on the test inputs), no `sprintf`.

Examples: `"123" + "877"` → `"1000"`, returns `4`;
`"99999999999999999999" + "1"` → `"100000000000000000000"`, `21`;
`"0" + "0"` → `"0"`, `1`; `"5" + "5"` with `capacity` 3 → `"10"`;
with `capacity` 2 → `-1`; `"12a" + "1"` → `-1`.

> [!TIP]
> Read: Beej's Guide to C, §7 Strings and §6 Arrays —
> https://beej.us/guide/bgc/html/split/strings.html
> "Add two numbers given as strings" (LeetCode #415) tests carry handling
> and off-by-one discipline at the ends of two arrays of different length.

Run `make run N=115`; check with `make test N=115`.
