# 062 — Virtual tables

Implement `Shape *shape_new_circle(double radius)`,
`Shape *shape_new_rectangle(double width, double height)`,
`double shape_area(const Shape *shape)`, `double shape_perimeter(const Shape *shape)`,
`const char *shape_name(const Shape *shape)` and `void shape_free(Shape *shape)`
in `062.c`.

The header defines the base type and its table of function pointers:

```c
typedef struct {
    double (*area)(const Shape *self);
    double (*perimeter)(const Shape *self);
    const char *(*name)(const Shape *self);
} ShapeVTable;
struct Shape { const ShapeVTable *vtable; };
```

This is exactly what a C++ compiler generates for a class with virtual
methods: every object starts with a pointer to a per-class table. In `062.c`
define two derived types whose **first member is the base**:

```c
typedef struct { Shape base; double radius; } Circle;
typedef struct { Shape base; double width, height; } Rectangle;
```

C guarantees that a pointer to a struct, converted to a pointer to its first
member, points at the same address (there is no padding before the first
member). So a `Circle *` can be handed out as a `Shape *` (`&circle->base`),
and inside a circle method `(const Circle *)self` gets it back. If `base`
were not first, that cast would read garbage.

Contract:

- Each constructor `malloc`s the derived struct, fills its fields, sets
  `base.vtable` to a `static const ShapeVTable` for that class, and returns
  `&object->base`. Return `NULL` if allocation fails.
- `shape_area`, `shape_perimeter`, `shape_name` do nothing but dispatch:
  `shape->vtable->area(shape)` and so on. They must not inspect the name or
  use `if`/`switch` on the kind.
- `shape_name` returns `"circle"` or `"rectangle"` (string literals; the
  caller never frees them).
- Circle: area `π r²`, perimeter `2 π r`. Rectangle: area `w h`, perimeter
  `2 (w + h)`. Use `M_PI` from `<math.h>` or write `3.14159265358979323846`.
- `shape_free(shape)` frees the object; `shape_free(NULL)` is a no-op.
  Since every derived object is one `malloc` block whose address equals the
  base address, `free(shape)` is correct.

Examples: circle radius `1` → area `3.14159...`, perimeter `6.28318...`,
name `"circle"`; rectangle `3 × 4` → area `12`, perimeter `14`, name
`"rectangle"`; radius `0` → area `0`.
