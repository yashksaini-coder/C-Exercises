# 027 — Palindromes, ignoring noise

Implement `bool is_palindrome(const char *s)` in `027.c`.

Return `true` when `s` reads the same forwards and backwards once every
character that is not a letter or a digit is ignored and letters are
compared case-insensitively. So `"A man, a plan, a canal: Panama"` is a
palindrome. The empty string and a string with no alphanumeric characters
at all (`",,,"`) are palindromes (nothing contradicts it). `s` is never
`NULL` and is not modified.

Use two indices moving inward. At each step skip forward over
non-alphanumerics on the left and backward on the right, then compare the
lowercase forms. The helpers `isalnum` and `tolower` from `<ctype.h>` are
allowed and encouraged — but pass them an `unsigned char`
(`isalnum((unsigned char)s[i])`): passing a negative `char` is undefined
behaviour, and the test includes a byte above 127. Do not build a filtered
copy; this must be O(1) extra space. The right index needs care: it is a
`size_t`, so do not let it go below `0` — stop as soon as `left >= right`.

Forbidden: `strlen` and everything in `<string.h>` (use `my_strlen` from
021, copied in, or a loop). `<ctype.h>` is allowed.

Examples: `"A man, a plan, a canal: Panama"` → `true`; `"racecar"` → `true`;
`"hello"` → `false`; `""` → `true`; `"0P"` → `false`; `"ab"` → `false`.
