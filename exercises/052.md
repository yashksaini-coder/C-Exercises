# 052 — Powers of two

Implement `bool is_power_of_two(uint64_t value)` in `052.c`.

Return `true` when `value` is `2^k` for some `k >= 0` (`1, 2, 4, 8, …,
2^63`), `false` otherwise. `0` is **not** a power of two, and that is the
classic bug: the trick `(value & (value - 1)) == 0` is true for `0` as
well, so you must test `value != 0` explicitly.

Why the trick works: a power of two has exactly one bit set; subtracting
one flips that bit and sets every bit below it, so the two values share no
set bits. Any other non-zero number keeps its top bit set after the
subtraction. The whole function is one expression, no loop.

Allowed: nothing from the library. Do not reuse `bit_count` from 051 (it
would work, but the point is the O(1) expression).

Examples: `is_power_of_two(1)` → `true`; `is_power_of_two(1024)` →
`true`; `is_power_of_two(0)` → `false`; `is_power_of_two(6)` → `false`;
`is_power_of_two(1ULL << 63)` → `true`; `is_power_of_two(UINT64_MAX)` →
`false`.
