# 083 — Binary file I/O

Implement `int write_records(const char *path, const Record *records, size_t count)`
and `ptrdiff_t read_records(const char *path, Record *out, size_t capacity)`
in `083.c`.

`Record` is the Stage 4 struct `typedef struct { int id; char tag[8]; double weight; } Record;`.

- `write_records(path, records, count)` opens `path` with `"wb"`
  (truncating) and writes the array with one `fwrite(records,
  sizeof *records, count, f)`. Returns `0` on success, `-1` if the file
  cannot be opened or fewer than `count` records were written. `count ==
  0` creates an empty file and returns `0`.
- `read_records(path, out, capacity)` opens `path` with `"rb"` and
  `fread`s up to `capacity` records into `out`, returning the number of
  whole records read (which may be `0` for an empty file and is at most
  `capacity`), or `-1` if the file cannot be opened. A trailing partial
  record is not counted. The return type is `ptrdiff_t`, a signed
  `size_t`, so `-1` fits.

Close the file on every path. `fwrite`/`fread` with the struct's
`sizeof` dump and reload the bytes of the struct exactly, padding included.

**Why this is not a file format.** As Beej's §9.6.1 warns, the bytes you
wrote depend on the compiler and machine: `sizeof(Record)` includes
padding between `tag[8]` and `weight` (here `int` 4 + `char[8]` + 4 bytes
of padding + `double` 8 = 24, but a different ABI may differ), the
integer and double are stored in the host's endianness, and `double` is
assumed to be IEEE 754. A file written on one machine may not read back on
another. It is fine for a cache or a temporary file consumed by the same
binary; for anything portable, serialise field by field in a defined byte
order (exercise 058 `pack` is the start of that). The exercise asks you to
do the naive thing *and* to be able to explain why it is naive.

The tests write to a temporary file under `build/` via `mkstemp` and
remove it afterwards.

Examples: write 3 records then read with capacity 8 → returns `3` and the
structs compare equal field by field; read with capacity 2 → returns `2`;
write 0 records → read returns `0`; `read_records("build/does-not-exist",
…)` → `-1`.
