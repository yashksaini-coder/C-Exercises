# 070 — Ring-buffer queue

Implement `int queue_enqueue(Queue *queue, int value)` and
`int queue_dequeue(Queue *queue, int *out)` in `070.c`.

`typedef struct { int items[8]; size_t head, count; } Queue;` — a FIFO of
capacity 8 stored in a circular buffer. `head` is the index of the oldest
element and `count` the number of live elements; the newest element sits at
`(head + count - 1) % 8` and the next free slot at `(head + count) % 8`.
The caller zero-initialises the queue.

Contract:

- `queue_enqueue` writes `value` into the next free slot and increments
  `count`; returns `0`, or `-1` when `count == 8` (nothing stored).
- `queue_dequeue` returns `-1` when `count == 0` (`*out` untouched);
  otherwise writes `items[head]` to `*out`, advances `head` to
  `(head + 1) % 8`, decrements `count` and returns `0`.

Neither operation moves elements: that is the point of a ring buffer. Both
are O(1). Use `ARRAY_LENGTH(queue->items)` for the capacity. The classic
first-attempt bug is forgetting the modulo on either index, which only shows
once the queue has wrapped around — hence the wraparound test.

Examples: enqueue `1, 2, 3`, dequeue → `1`, enqueue `4`, dequeue →
`2, 3, 4`; 8 enqueues succeed, the 9th → `-1`; enqueue 8, dequeue 5,
enqueue 5 (wraps past index 7) and dequeue everything in order.

> [!TIP]
> Read: Beej's Guide to C, §6 Arrays — https://beej.us/guide/bgc/html/split/arrays.html
> Ring buffers are the standard structure for producer/consumer queues in
> drivers and audio code; interviewers ask it to check modulo indexing.
